# OpenSpec-lite

Living truth is `openspec/specs/<capability>/spec.md`.
In-flight work is `openspec/changes/<id>/` — read the banner.
PENDING is a draft. PARKED is not work. ACTIVE BUILD is the write.

Restore / typo / pin / comment: direct fix, no change.
New behavior: verb-led change-id, `proposal.md` + `tasks.md` + deltas.
`design.md` only when cross-cutting or security.

Do not implement PENDING or PARKED.
Fold after the owed work has landed.
