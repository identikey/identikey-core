## Blind take (written before opening design.md / tasks.md / steer.md / delta)

1. Pin the bind bytes: one canonical encoding of the 7-tuple (CBOR array or length-prefixed), with a fixed vector, cited to a Mjolnir verifier rev. The OP must not own or invent that encoding.
2. Pin a new consent domain (v2 tag or a versioned digest) that hashes session key, operation, resource, and channel. Do not change what the v1 tag hashes, and keep the v1 vector.
3. Pin cross-protocol separation: one Ed25519 seed signs both the identikey-auth Response payload and the bind tuple. Prove that neither preimage can parse as the other.
4. Pin atomicity: one claim, one decrypt, two signatures, one commit. A failure between them fails both. `indeterminate` covers both. Retrieve returns both or neither.
5. Pin that the bind's challenge element equals the attempt's stored Challenge bytes. The caller does not supply it twice.
6. Pin input limits: session key alg and length, byte caps on operation, resource, and channel, and a charset for the displayed strings. Reject at begin, before key access.
7. Pin who renders consent. The OP page (A3) or the wallet (A4) renders from the stored row. The caller does not. A4 needs the preimage so the wallet can recompute the digest.
8. Refuse: the OP checking the Mjolnir connection, a second bind domain, a separate key-use claim for the bind, a bind added to an attempt that already completed, C1, Schnorr.
9. Refuse: the bind-less path silently becoming the bind path (or the reverse). The mode is fixed at begin and immutable.
10. Tradeoff: raw channel bytes on a consent screen mean nothing to a human. The display is fidelity, not comprehension. The real defense is the edge checking channel and holder. Say so; don't claim the user verified the channel.

## Blocking (send-back)

**B1 — Operation and resource are strings here and tuples in the contract.** The edge signs `["vms","stop"]` (two components). `["vms:stop"]` (one component) is also a valid CanonicalTuple, and its bytes differ. The design stores and hashes `vms:stop` as one UTF-8 string. Nothing says how the OP gets from that string to the tuple it must CBOR-encode. Splitting on `:` is an invented mapping, and it breaks for resources such as `vm-1` or ids that contain `:`. Consent therefore commits to a string that maps to more than one signed bind. That is the "second bind domain" the packet forbids, arriving through the field model. Fix: begin takes `operation` and `resource` as arrays of components with the contract's charset. The consent transcript hashes the component count, then each length-prefixed component. The OP builds `bind_signing_bytes` byte-for-byte. Pin a joint vector that reproduces Mjolnir's `direct_challenge_canonical_bind_vector` hex, and re-pin the consent digest.

**B2 — The session key and channel representations do not match the contract, and no caps exist.** The contract encodes the session key as a ClassicalPublicKey map (`{alg:"ed25519", key:h'…'}`), not as 32 raw bytes. D5 can stay Ed25519-only as a declared subset of the edge's Ed25519|P-256. But the signed bytes must be the map, and the delta must say "subset". The contract's channel is exactly 32 bytes (Blake3). D5's length-prefixed variable channel accepts values the edge can never accept, so begin should refuse anything other than 32 bytes. Pin caps at begin, before the row is stored: max components and max component length for operation and resource, and the exact channel length. Today only the Challenge has a body cap.

**B3 — "Consent SHALL show" names no surface and has no test.** No hosted consent page exists for `/managed-challenge`. For A3 the OP returns WebAuthn options to the *caller*. The assertion's challenge is the library's random value, bound by the server row, not by the digest. So the only party that "shows" the fields is the caller that chose them. For A4 the wallet receives only the consent Challenge, whose nonce is an opaque digest, and cannot show fields it never received. Pick one and pin it:
- (a) Name the renderer and its inputs. Begin returns the stored bind fields beside `consent_challenge`. An A4 wallet recomputes the digest from them and refuses on mismatch. An A3 caller renders them. Say plainly that a malicious caller can misrender, and that the edge's channel and policy checks are the backstop.
- (b) Drop "show" and state "the consent transcript commits to" those fields.

Either way, add a task and a scenario that test the chosen rule.

## Owed, non-blocking (fix in the same pass)

- **N1** — The delta still carries "Fresh consent signs the exact Challenge" with no bind fields in its GIVEN. That contradicts "Begin SHALL reject a request that omits any of them". Fold it into the new "Response and the bind" scenario or add the bind to its GIVEN. Record "bind is mandatory; the bare responder is withdrawn" as a design decision with its why. Steer did not decide it, and it narrows a living surface to one RP.
- **N2** — The living text stores the Response in the same commit as the completion audit. Extend that to the bind signature, and have the completion audit record operation, resource, and the session-key fingerprint. The bind is the authority-bearing artifact.
- **N3** — Attempts begun before the migration have no bind columns. Finish must terminalize them. It must not rebuild a v1-prefix transcript with empty bind fields. Add a test.
- **N4** — State the cross-protocol separation (3-array identikey-auth payload vs 7-array bind) as a design line and a unit assertion.
- **N5** — Retrieve's wire shape for the bind is not pinned: field name, the 64-byte signature as unpadded base64url, and whether the fields are echoed. Pin it so `mjolnir-22ff.4`/`.6` can consume it.
- **N6** — Finish receives no bind fields, so "Finish SHALL reject a bind that differs" needs a concrete form. The test is A4: an Elect signature over a consent Challenge whose digest used `["vms","start"]` is rejected before decrypt.
- **N7** — The proposal's preparation note says "Banner stays PENDING", but the banner reads ACTIVE BUILD (`029fb2a`, Mjolnir `68dcc4d` grant). Reconcile the note. This reader did not touch the banner.
