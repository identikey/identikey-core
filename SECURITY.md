# Security

Report a vulnerability in private. Do not open a public GitHub issue,
and do not post exploit details, credentials, or account data in a
public channel.

Use **Report a vulnerability** on the
[Security tab](https://github.com/identikey/identikey-core/security/advisories/new).
That opens a private advisory for the maintainers of this repository.
It covers `identikey-core` and the production provider at
`https://auth.identikey.me`.

Include:

- What an attacker can do, and who is affected
- The component (hosted provider, a crate, or the web app)
- The version, commit, or production observation
- Steps to reproduce, or why a reproduction is not safe to run

Give us time to confirm and fix the issue before any public write-up.
We will answer on the advisory.

Please do not access another person's account, change their data, or
interrupt the service in order to demonstrate a finding. A description
plus a proof against your own account or a local checkout is enough.
If a proof needs something you should not send, say so in the report
and we will arrange it.

Feature requests and ordinary bugs belong in
[issues](https://github.com/identikey/identikey-core/issues).
